# Prabodhan Bag Demo

Responsive, offline-friendly client prototype for the Prabodhan Bag production workflow. It is built with plain HTML, CSS, and JavaScript and uses fictional data stored only in the browser.

## Demo login

- Admin: `ADMIN` / `DEMO123`
- Worker: `WORKER` / `DEMO123`

## Run locally

Open `index.html` directly, or serve this folder with any static web server.

## Deploy on Vercel

1. Import the `Amit-coder-98/PWE` GitHub repository in Vercel.
2. Leave the Root Directory as the repository root.
3. Select **Other** as the framework preset.
4. Leave Build Command and Output Directory empty.
5. Click **Deploy**.

Vercel will automatically deploy updates pushed to the `main` branch. Use a separate feature branch when you want a preview link before publishing to production.

## Important

This is a presentation prototype. It has no backend and does not connect to the live Prabodhan Bag API or real customer data.
